# Retail Business Intelligence & Performance Analytics

## Objective
Analyze retail transaction data to identify revenue, profitability, customer, regional and product performance drivers, then translate findings into management recommendations.

## Workflow
Raw CSV → SQL analysis → Python EDA → Power BI dashboard → recommendations

## Suggested KPIs
- Total Revenue
- Total Profit
- Profit Margin
- Orders
- Units Sold
- Average Order Value
- Revenue by Region
- Profit by Category
- Discount vs Profit

## Getting started
1. Create a Python virtual environment.
2. Install `requirements.txt`.
3. Run `src/analysis.py`.
4. Load `data/raw/retail_sales.csv` into Power BI.
5. Build the dashboard using the specification in `docs/powerbi_dashboard.md`.
6. Replace the synthetic dataset with a public dataset if desired.

## Important
The included data is synthetic and intended for portfolio development. Do not claim that the findings represent a real company.
